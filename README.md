# Hội An Commercial Property Website

Files:
- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — language toggle, photo lightbox, copy-phone button
- `assets/` — optimized property photos and QR code

## Publish on your existing GitHub Pages site

Repository: `house-rental`

1. Delete the old temporary `index.html`.
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder to the repository root.
3. Commit the changes.
4. GitHub Pages should update automatically at:
   https://hlam02.github.io/house-rental/

## Important
The listing currently says “Hội An” based on the location shown in the photos.
If you want the exact street/address, add it before publishing publicly.
